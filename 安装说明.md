# 李喜 skill 安装说明

> **技能名**：`lixi-reverse`（触发词：**李喜**）  
> **版本**：1.6.0 · 43 文件 / 407 KB · 22 个纯 Python 脚本 · 16 篇参考资料 · 14 个真实案例  
> **依赖**：Python 3.8+（只用标准库；`capstone` 可选、`cryptography` 仅 `v2parse.py` 需要）  
> **平台**：Windows 上跑分析脚本；目标平台是 Android（APK/dex/.so/.ko）

---

## 一 · 目录结构

```
李喜skill\
├─ lixi-reverse\        ← 技能本体（原样放进 DSH 的 skills 根目录即可）
│   ├─ SKILL.md                   ← 入口（DSH 靠它识别技能）
│   ├─ VERSION
│   ├─ references\01..14          ← 14 篇方法论/案例
│   ├─ scripts\  (20 个 .py)      ← 全部纯 stdlib，无第三方依赖
│   └─ templates\case-agents-template.md
├─ 一键安装.ps1                   ← 自动探测 skills 根并复制（幂等、可 -DryRun）
├─ MANIFEST.json                  ← 43 个文件的 sha256（核对用）
└─ 安装说明.md                    ← 本文件
```

**要点：目录名必须是 `lixi-reverse`。** DSH 的 filesystem provider 只认  
`<skills根>/<技能名>/SKILL.md` 这一层结构，改名会导致技能不被识别。

## 二 · 安装（四种方式，任选）

### 方式 0 · 从 zip 装（跨机器传输先做这步）

```powershell
# 解压 lixi-reverse-1.6.0.zip → 得到 李喜skill\ 目录，然后按方式 A 跑一键安装.ps1
Expand-Archive "lixi-reverse-1.6.0.zip" -DestinationPath "D:\"
```

> `一键安装.ps1` 存的是 **UTF-8 with BOM**：Windows PowerShell 5.1 与 pwsh 7 都能正确解析中文。

### 方式 A · 一键安装（推荐）

```powershell
# 先演练，看清会往哪写（不落盘）
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\李喜skill\一键安装.ps1" -DryRun

# 确认后正式装（自动探测 DSH 的 skills 根）
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\李喜skill\一键安装.ps1"

# 目标机 skills 根不在常见位置时，显式指定
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\李喜skill\一键安装.ps1" -Target "D:\某处\skills"
```

脚本会：探测 skills 根 → 复制 → 跑 `selftest.py` 自检 → 打印下一步。  
**幂等**：重复执行会覆盖技能目录（不碰别的技能）。

### 方式 B · 手工复制

把 `lixi-reverse` 整个目录复制到 DSH 配置里的 `customSkillDirs` 所指目录下，例如：

```
D:\ai逆向课程\课程\deepseek-harness\skill\先解压这个是智能体\xiaotao-win-deepseek\skills\
  └─ lixi-reverse\   ← 放这里
```

然后**重启会话**（或等 `watch: true` 自动发现）：技能目录里应出现 `lixi-reverse`。

### 方式 C · 目标机还没配 skills 根

编辑 `<DSH_PROFILE_DIR>\cordis.patch.yml`（通常在 `%USERPROFILE%\.dsh\profiles\<profile>\`），  
找到 `skill-filesystem` 插件的配置，把父目录加进 `customSkillDirs`：

```yaml
          - id: skill-filesystem
            name: '@deepseek-ai/dsh-skill-filesystem'
            config:
              customSkillDirs:
                - 'D:\李喜skill'          # ← 加这一行（父目录，不是技能目录本身）
              watch: true
```

保存后重启 DSH。**注意**：`customSkillDirs` 要填**技能的直接父目录**，填到 `lixi-reverse`  
本身会识别不到。

## 五 · 常见问题

| 现象                                  | 原因                     | 处理                                                |
| ----------------------------------- | ---------------------- | ------------------------------------------------- |
| 技能列表里看不到                            | 目录名不对 / 层级多了一层 / 没重启   | 确认 `<root>/lixi-reverse/SKILL.md` 存在              |
| 说「李喜」没反应                            | 技能未注册 / 描述未加载          | 检查 `customSkillDirs`；重启 DSH                       |
| 脚本报 `ModuleNotFoundError: capstone` | 该系统 Python 没装 capstone | 无影响（自动降级）；要反汇编就 `pip install capstone`            |
| `v2parse.py` 报缺 `cryptography`      | 该库只它用                  | `pip install cryptography`，或跳过它（其余脚本不受影响）         |
| 路径含中文报错                             | 个别旧版 Python 的控制台编码     | 设 `$env:PYTHONIOENCODING='utf-8'`；脚本已内置 utf-8 重定向 |
| 脚本输出乱码                              | 终端是 GBK                | 同上；或 `chcp 65001`                                 |

## 七 · 校验包完整性

```powershell
$root = "D:\李喜skill"
$man = Get-Content "$root\MANIFEST.json" -Raw | ConvertFrom-Json
$bad = @()
foreach ($f in $man.files) {
  $p = Join-Path "$root\lixi-reverse" $f.path
  if (-not (Test-Path $p)) { $bad += "缺: $($f.path)"; continue }
  if ((Get-FileHash $p -Algorithm SHA256).Hash.ToLower() -ne $f.sha256) { $bad += "改: $($f.path)" }
}
if ($bad) { $bad } else { "OK：$($man.files.Count) 个文件全部一致" }
```
