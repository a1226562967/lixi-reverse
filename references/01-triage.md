# 判层 — 拿到样本的前 30 分钟

> 目的只有一个：**判出"这一层的锁是什么、能不能本地破"**，再决定要不要动手。
> 判错层的代价是整晚浪费（实证：花整晚破载荷面的卡密，最后证明是 Ed25519 服务端签名，而 APK 层两字节就过）。

---

## 一 · 三层表（先看这张）

| 你在哪一层 | 典型载体 | 判决通常在哪 | 能不能本地破 | 打法 |
|---|---|---|---|---|
| **控制面** | APK / dex / Kotlin/Compose | 常是**本地**（JSON 字段、布尔、状态槽） | ✅ 多半能 | `02-apk-layer.md` |
| **脚本面** | 壳里的 `.lua`（AppLua/GG 系/AideLua/AndroLua） | 常在**脚本**里（`if f.code==1`）；服务端签名只保护"来源" | ✅ 能（改脚本+重签） | `12-lua-script-layer.md` |
| **载荷面** | `.so` / 下载的 ELF | 常见**服务端 + 签名** | ❌ 伪造不行，**重放可以** | `03/04` + `05-server-verdict.md` |
| **特权面** | 内核模块 / root 脚本 | 与授权无关，但是**硬前提** | — | `06-kernel-module.md` |

## 二 · 判「哪一层」的 30 分钟办法

### 2.1 三问（算法无关，先答这个）

| 问 | 判据 | 结论 |
|---|---|---|
| **① 判决字段是本地的还是服务端下发的？** | 搜该字段在客户端有没有"本地的成功值/成功分支"；只有 `optXxx(...)` 读取、没有本地赋值 → 服务端 | 本地→可破；服务端→只能绕过显示 |
| **② 客户端里有没有这个判定的文本？** | 把运行时看到的提示语拿去 payload 里搜字节 | 搜得到→本地；搜不到→服务端驱动 |
| **③ 有没有签名/认证挡住响应伪造？** | 搜 `Ed25519` / `EdDSA` / `X25519` / `签名无效` / 证书固定 | 有→伪造死路，走重放；无→可做假服务器 |

> **强特征才收**：`Signature`/`signature` 在 bouncycastle/okhttp 里必然出现，属库噪声，不代表客户端验签。
> `autotriage.py` 只认 `Ed25519/EdDSA/X25519/HmacSHA256/签名无效/verifyResponse/signCheck/antiTamper`。

### 2.2 三条快捷判据

```powershell
# ① 一条命令（自动做上面三问 + 判层 + 判型）
python scripts\autotriage.py 样本

# ② 只想快速看形态
python scripts\elfprobe.py 样本        # 加壳/自解密/密文/伪代码 + filesz=0 段
python scripts\koprobe.py  样本        # e_type=1 就是 .ko

# ③ APK：两分钟看结构
python scripts\dexql.py classes.dex --classes --static --decoders --gates
```

### 2.3 载体判型（扩展名一票否决权都没有）


ELF 再看 `e_type`（0x10）：`01=REL(.ko)` `02=EXEC` `03=DYN(PIE/so)`。

### 2.35 脚本层与追加容器的两个专用判据

| 看到 | 结论 | 下一步 |
|---|---|---|
| `assets/` 成规模 `.lua` + dex 有 `org/luaj/vm2` + `libkeystone*.so`/`AGG_LUA_API_*` | **脚本层**：别去 dex 找 `if-eqz` | `12-lua-script-layer.md` |
| `.text` 熵正常（6.0–6.5）但**文件尾一大块熵 7.9+** | **追加容器**：明文 loader + 尾部加密容器 | `python scripts\container.py <elf>` → `13` |
| `e_shoff=0` 但后段能暴搜出合法节表 | 只是字段被清零 | `container.py --recover-sht` |
| `.rodata` 一块高熵但**零字节占比 3–25%** | **资源块，不是加密**（真密文零字节 0.3–0.5%） | 别当第二层壳啃 |

### 2.4 分发粒度反推（5 秒）

| 分发粒度 | 保护形态 |
|---|---|
| 按 `uname -r` 逐内核版本各一份 | 内核态载荷（无 libc / 无符号解析） |
| 按游戏版本各一份 | 用户态外挂（硬编码偏移） |
| 一份走天下 | 用户态 + 运行时扫描 |
| 按 ROM 厂商 | 系统服务/框架层改写 |

## 三 · 判据速查表（数值化，全部来自实测标定）

| 判据 | 阈值 | 出处 |
|---|---|---|
| 熵（4KB 窗） | <4 头/表 · 5.5–7.2 代码 · 7.7–8.0 加密/压缩 · ≈7.99+16B 零重复 = 强加密 | 03 |
| `top1` 字节占比 | CIPHER: 熵>7.85 且 <1.2%；OBF: 熵>7.5 且 ≥1.2%（理论下界 0.39%，OBF 实测 2–6%） | 04 |
| 6-gram 归一化唯一率 | <0.75 代码 / 0.75–0.97 混合 / >0.97 非编译产物（实测 0.373 / 0.506 / 0.979 / 1.000） | 04 |
| ADRP 引用密度（配对） | 代码 ≈5000–5200/MB · 伪代码填充 ≈50/MB · 密文 0（且密文区不可采信） | 04 |
| 自解密四指纹 | 入口在 RX 段尾 + `DC CVAU`(0xD50B7B20)/`IC IVAU`(0xD50B7520) + 写后跳 + 区间不重叠 | 03 |
| 商业加固最强判据 | LOAD 段 **`filesz=0` 而 `memsz` 巨大**（实测 2 段合计 36.1 MB） | 03 |
| dump 体五指纹 | `vaddr==p_offset` / 无节表 / entry 失效 / 尾部追加段 / 段权限错标 | 04 |
| `.ko` 判型 | `e_type=1` + `vermagic/name/license/depends/import_ns` | 06 |
| 极小 dex | 几 KB 的独立 dex = 解码器（实测 2292 B / 52 条串） | 02 |
| APK 加固信号 | 只有一个几十 KB 的 dex；或 dex 几 MB×N（未加固） | 02 |

## 三.5 · 判完层之后：五条路线怎么选（成本从低到高）

| 先决条件 | 走哪条 | 成本 | 交付 |
|---|---|---|---|
| 判决在本地 + 载体是 APK/dex | **A 控制面字节补丁**（`02`） | 最低（常 2 字节） | 重打包装机后功能可用 |
| 载体是 **Lua 脚本壳** | **F 脚本层改判**（`12`） | 低（改文本 + 重签） | 任意卡密进主界面 |
| ELF 是**追加容器**（明文 loader + 尾容器） | **G 静态全解包**（`13`） | 中（读 loader 复刻） | 明文产物 + 终检哈希自证 |
| 判决在本地 + 载体是 ELF + **有 root 但反调试强/不能改盘** | **E 运行时打桩**（`11`） | 低（内存改 + 喂狗） | 功能可用且活过 2× 检测周期 |
| 判决在本地 + ELF 全加密/函数级加密，但**能改盘且无完整性校验** | **B 脱壳后静态改**（`03`/`04`） | 中 | 明文产物 + ≥2/4 验证 |
| 判决在**服务端** + **有有效卡** | **C 真响应重放**（`05`） | 常数（抓一次） | 断网能进主界面 |
| 判决在服务端 + 无有效卡 | 只能啃客户端找"服务端结论的消费点" | 高 | 或如实报"不可破" |
| 特权面（`.ko`） | **D 只做前提确认**（`06`） | 10 分钟 | 能力面表（不是授权） |

**两条反直觉的排序**：
1. **"能改盘但会被自检" ⇒ 走 E 不走 B。** 起源就是：`DISK ELF NEVER PATCHED`，静态改盘 = SIGSEGV。
2. **"有 VM" 不等于"必须逆 VM"。** 只要判决在客户端，打 native 边界（跳板 `br` / 返回值 / out 参数 / PLT）就够了。

### 2.36 看到这些防守特征 → 直接跳对应打法

| 看到什么 | 说明对方做到了 | 我们的打法 |
|---|---|---|
| 客户端只改 `isLicensed` 就通 | **服务端没独立鉴权** | 一条补丁（`02`） |
| 新鲜度只比时间戳 / 只比 nonce 回显 | 单维新鲜度 | 冻结时钟 / 缓存心跳 / 重放（`05`） |
| 心跳失败只是重连 | 它是**链路保活**不是授权闸 | 只打登录闸即可 |
| 心跳失败直接停功能 | 它是**授权闸** | 登录 / 心跳 / 环境三处同改（`12` §五、`11` §九） |
| 只校验 `.text` 哈希 | 代码段外不设防 | **PLT/GOT/vtable 打桩**（`11` 形态 D） |
| 模块枚举（maps/dl_iterate_phdr） | 只查已加载模块 | 手工映射 / `/proc/pid/mem` 不 attach（`11` §六） |
| 标称"虚拟化"但入口是普通跳板 | 只是混淆/压缩 | 先判形态（`04`），别逆 VM |
| 有"已保护范围/排除项" | 必有未保护区（第三方/FFI/JIT） | 按段算覆盖，找明文段（`13`） |

## 四 · 常见误判（都真实发生过）

| 误判 | 后果 | 正解 |
|---|---|---|
| 看到高熵就判"密文" | 整晚试解一块**混淆指令流** | 先 `top1` 粗筛（OBF 的 top1 ≥1.2%） |
| 看到 `DCB` 就判"解不出" | 整条路线走错 | `DCB` 是工具态；先 `reanalyze_range`/`make_code` |
| 按 `vaddr` 直读 `.data` | 得到"0 条数据"的假否定 | 先建 `v2o()` 映射（实测 delta 0xC000，修正后才拿到 49,110 条） |
| 把同厂商另一样本的坐标套过来 | 全错 | **判据可迁移，坐标一律重推** |
| 把数据表里的编号当凭证 | 追错目标 | 表里的编号先当数据（`PASS-90xxxx` 是物资 ID，不是卡密） |
| 只改"显示"字段 | 界面变了但功能仍锁 | 先分清"门禁"与"显示"（只被 UI 读的到期时间不管） |
| 只关总开关不建会话态 | 后续请求全废 | 联网强制握手的模型要建立会话（见 `05`） |

## 五 · 判层结论怎么写（写进案件锚点）

```
层: 控制面(APK) / 载荷面(ELF) / 特权面(.ko) / 包装层(shell+gzip)
判决归属: 本地 / 服务端 / 未知(缺证据)
证据等级: observed（我实测到什么） / inference（推断，待验） / unknown
下一层缺口: 缺哪个输入（设备？有效卡？一次抓包？）
```

> **"卡在第几层、缺哪份输入"是有效结论**；"差不多能脱"不是。
